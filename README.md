# Murchison for Ward 4

Campaign website for James Murchison, candidate for City Councillor,
Ward 4 – Kanata North, in the 2026 Ottawa municipal election
(election day: Monday 26 October 2026).

Live site: https://james-murchison.github.io/

A single static page — no build step, no dependencies, no tracking.

| File | What it is |
|---|---|
| `index.html` | The whole site: content and structure |
| `styles.css` | All styling |
| `main.js` | Collapsible sections, highlighter animation, navigation |
| `james-portrait.jpg` | Cover photo |
| `james-booth-blurred.jpg` | Strong Towns Ottawa booth photo |
| `.nojekyll` | Tells GitHub Pages to serve the files as-is |
